# AI-Powered Insurance Image Forensics

Detects vehicle details, damage, license plates, color, and helps flag potential fraud/tampering for Kenyan insurance claims.

## Features
- Front & rear license plate detection
- Vehicle type filtering (car, motorcycle, bus, tuk-tuk, lorry)
- Damage severity scoring
- Vehicle color detection
- Unique ID with timestamp for every processed image

## Tech Stack
- FastAPI
- YOLOv8 / YOLOv11
- EasyOCR
- OpenCV
- Deployed on Render (free tier)
